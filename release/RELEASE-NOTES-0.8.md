# Offline DAoC True 1.65 v0.8

Download **Download-OfflineDAoC-True165-v0.8.zip**, extract it, and start
**GET-OFFLINE-DAOC-TRUE165.cmd**. Choose Update my game for an existing
True 1.65 installation, or New install for a fresh world. The downloader
shows the download size before starting. The launcher refreshes the world
content on the first START SERVER.

- Hired parties share Realm Points in RvR and XP from enemy gamebot kills.
  Low-value battleground kills no longer round an eligible mixed-party RP share to zero.
- Battleground gamebots organize keep assaults and advance through the opened gates.
- Trollheim has seven restored period drops and the level-69 Remandun den Laerd.
  Companions have a route out of the reported pillar.
- The Realm Exchange refreshes My Listings, the enchant bonus menu scrolls, and
  stable rides and bridge dismounts use corrected models and positioning.
- Both offline reference tools are included under `tools`. Open the database's
  `index.html` in a browser. The crafting guide includes a 64-bit Windows executable
  with Python bundled, plus a Python/Tk source entrypoint.

The cumulative patch includes compatibility hashes for v0.1 through v0.7,
including v0.4.1. Only v0.7 was available for full upgrade and progress-transfer
testing. See the [changelog](https://github.com/zomboden/OfflineDAoC-True165/blob/main/CHANGELOG.md)
for the full list of changes.
